# Heart Disease Detection Using Vision Transformer (ViT)

## Overview

Heart Disease Detection Using Vision Transformer (ViT) is an AI-powered healthcare application that analyzes ECG images and predicts heart-related conditions. The system uses a fine-tuned Vision Transformer (ViT) model trained on ECG image datasets and provides disease predictions, confidence scores, explanations, and healthcare recommendations through a user-friendly Streamlit web interface.

---

## Features

* Upload ECG images
* AI-powered ECG analysis
* Heart disease prediction
* Confidence score display
* Disease explanation
* Healthcare recommendations
* Interactive medical chatbot
* Streamlit-based web interface

---

## Supported Classes

The model can classify ECG images into the following categories:

1. Normal ECG
2. Abnormal Heartbeat
3. Myocardial Infarction
4. Post MI History

## Model Architecture

This project uses:

```text
google/vit-base-patch16-224
```

The Vision Transformer (ViT) model was fine-tuned on ECG image data to classify heart conditions.
